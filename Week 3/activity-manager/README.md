# Activity Manager v1

Proyek Modul 3 - Frameworks in Programming (Laravel Basic)

## Versi yang digunakan
- PHP: 8.4.0
- Composer: 2.8.12
- Laravel: (isi hasil `php artisan --version`)

## Cara menjalankan
1. `composer install`
2. `copy .env.example .env`
3. `php artisan key:generate`
4. `php artisan migrate --seed`
5. `php artisan serve`
6. Buka `http://127.0.0.1:8000/activities`
