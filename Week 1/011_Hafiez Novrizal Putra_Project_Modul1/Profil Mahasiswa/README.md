Website profil pribadi sederhana berbasis HTML & CSS untuk menampilkan informasi diri, keterampilan, dan kontak seorang mahasiswa D3 Teknik Informatika.


Halaman ini terdiri dari:
- **Navbar** — judul "Profil Mahasiswa" dan navigasi ke bagian Tentang, Keterampilan, dan Kontak
- **Section Tentang** — foto profil dan deskripsi singkat diri
- **Section Keterampilan** — daftar kemampuan (HTML, CSS, Problem Solving) dalam bentuk kartu
- **Section Kontak** — tautan kirim email dan nomor telepon
- **Footer** — hak cipta tahun berjalan


Struktur
├── index.html                              # Struktur halaman profil
├── style.css                               # Styling (navbar, kartu, responsif)
├── Tampilan_Muka_Hafiez_Novrizal_Putra.png # Foto profil
└── README.md                               # Dokumentasi proyek ini
```

Fitur Tampilan
- Navbar fixed berwarna hitam dengan tombol navigasi yang berubah warna saat hover
- Foto profil bulat (circular) dengan efek bayangan (shadow)
- Kartu-kartu section (Tentang, Keterampilan, Kontak) berwarna putih dengan sudut membulat dan bayangan lembut
- Tombol "Kirim email" dengan gaya outline
- **Responsif** — tampilan menyesuaikan pada breakpoint 768px (tablet) dan 480px (mobile), termasuk perubahan padding, arah navbar, dan lebar kartu keterampilan

Teknologi yang Digunakan
- HTML5
- CSS3 (Flexbox, Media Query, box-shadow)
